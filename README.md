# SmartStudy

A complete, responsive front-end for an academic resource recommendation workspace. It is built from the supplied SmartStudy prototype and runs without a build step or server.

## Run it

Open `index.html` in a modern browser, or serve this directory with any static file server.

## Included interactions

- responsive navigation with a mobile drawer
- resource search, filters, topic preferences, and sorting
- saved resources persisted in `localStorage`
- accessible resource details dialog with safe external links
- course-specific study plans with locally persisted task completion
- keyboard shortcut: <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>K</kbd> opens resource search
